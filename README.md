# React Native Pet Project: Todolist App

## Get started

1. Install dependencies

```bash
npm ci --ignore-scripts
```

2. Start the app (iOS/Android/Web)

```bash
npm run ios
```

```bash
npm run android
```

###### for android - in /android/local.properties add sdk.dir

```bash
npm run web
```

## Environment

🖥️ Developed and tested on macOS (for iPhone 12 mini)

⚙️ Node.js: 22.17.0

📦 npm: 11.4.2

❗ Windows is not officially supported

###### For IOS you need to have installed XCode
